## A. Confirmed errors — need the ministry to supply the correct reference

### 1. Ruth, day 2 — `cross_references`
```
current:  ኢሱ 24:15
```
`ኢሱ` is not a book of the Bible. Almost certainly a typo for **ኢያሱ** (Joshua).
Joshua 24:15 is "choose you this day whom ye will serve" — which fits the day's
topic ("Decision") exactly.
**Proposed fix:** `ኢያሱ 24:15` — please confirm.

### 2. Psalms, day 18 — `cross_references`
```
current:  ዘዳ 18:23
```
Deuteronomy 18 has only **22 verses**. Either the verse or the chapter is wrong.
**Needs the ministry to supply the intended reference.**

### 3. 1 Timothy, day 1 — `cross_references`
```

```
Two problems. 1 Timothy 1 has only **20 verses**, so `1:22` cannot be right. And
two references are joined by a colon rather than a separator, so the intent is
unclear — it may be `1:2` + `5:8`, or something else.
**Needs the ministry to supply both intended references.**

## C. Not errors — parser handles these, logged for awareness

**Reference chaining.** Several entries omit the book or chapter because it
carries over from the preceding reference in the same string:

- `1፡15፣16` (1 Tim day 2) — means 1:15 **and** 1:16, chapter inherited.
- `ሉቃ 1:80፣ 2፡52` (1 Tim day 8) — `2:52` is **Luke** 2:52, book inherited. Note
  this is genuinely dangerous to get wrong: read without inheritance it resolves
  to 1 Timothy 2:52, which does not exist.

The parser must inherit book and chapter from the previous reference in a list.
This is normal Bible-citation style, not a data error.

## D. Normalisation the importer will apply automatically

No ministry action needed — recorded so the transformation is not a surprise.

- `፡` and `:` are used interchangeably as the chapter/verse separator → both
  accepted, stored canonically.
- `፤` and `፣` are both used as list separators → both accepted.
- `verses` values are wrapped in parentheses → stripped.
- **Psalms has no `verses` field at all** — the passage is embedded in the topic
  string (e.g. `"Psalm 42 - God's Ceaseless Presence"`). The importer extracts it
  from the topic for this book. Going forward the dashboard should require an
  explicit canonical reference on every day.
- Per the agreed model: a reference with no verse range means **the whole
  chapter**.
